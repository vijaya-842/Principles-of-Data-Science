# Principles of Data Science

> Python | Pandas | NumPy | Scikit-Learn | Statistical Analysis

Coursework and applied assignments from the **Principles of Data Science** course
at the University of Missouri-Kansas City — covering core data science methodology,
statistical analysis, and machine learning fundamentals.

---

## Assignments

### Assignment 1 — Exploratory Data Analysis
End-to-end EDA on real-world datasets across two domains:

#### Frailty Analysis (Clinical Data)
- Data ingestion, cleaning, and validation of clinical patient records
- Statistical summarization of frailty indicators
- Full pipeline: Raw data → Cleaned data → Analytical insights

#### Student Performance Analysis (Education Data)
- Cleaned and analyzed academic performance records
- Identified grade distribution patterns and performance drivers
- Visualized subject-wise trends and demographic breakdowns

---

### Assignment 2 — Data Wrangling & Feature Engineering
Applied data wrangling on a structured dataset (`train.csv`) using core
data science libraries.

**Key Work:**
- Data loading, inspection, and type validation with Pandas
- Feature engineering using NumPy and datetime transformations
- Cleaned and structured raw data into ML-ready format
- Statistical analysis and summarization of key features

**Tech:** Python, Pandas, NumPy, datetime, Google Colab
